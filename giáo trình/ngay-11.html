1. Mục tiêu

Phân biệt trình duyệt, máy chủ và PHP; kiểm tra PHP cùng Composer; chạy một tệp PHP trên dòng lệnh và qua máy chủ phát triển; kết hợp PHP với HTML và tách cấu hình vào một tệp riêng.

Trong bài này bạn làm việc trên máy cá nhân với dữ liệu mẫu. Không đưa mật khẩu hay API key thật vào các tệp thực hành hoặc Git.

2. PHP hoạt động ở đâu?

Trình duyệt gửi HTTP request tới máy chủ. Máy chủ chạy mã PHP, tạo response, chẳng hạn HTML, rồi gửi kết quả về trình duyệt. Trình duyệt hiển thị HTML nhận được; thông thường người xem không thấy mã PHP đã chạy trên máy chủ.

Trình duyệt → HTTP request → Máy chủ chạy PHP → HTML response → Trình duyệt

PHP cũng có thể chạy trong terminal bằng giao diện dòng lệnh (CLI), không cần trình duyệt. PHP không thay thế HTML/CSS: PHP tạo hoặc xử lý dữ liệu, còn HTML mô tả nội dung và CSS định dạng giao diện.

Ví dụ đầu tiên

<?php
echo "Xin chào PHP!";

<?php bắt đầu khối PHP; echo in dữ liệu; dấu chấm phẩy kết thúc câu lệnh. Khi tệp chỉ gồm PHP, có thể bỏ thẻ đóng ?> ở cuối.

3. Môi trường: PHP, Composer và XAMPP

PHP CLI chạy lệnh PHP từ terminal. Composer quản lý các thư viện PHP của dự án. XAMPP là bộ công cụ có thể cung cấp Apache, PHP và cơ sở dữ liệu để học trên máy tính. Không cần cài nhiều bản chỉ để làm ví dụ hôm nay.

Trên Windows, mở PowerShell rồi chạy:

php -v
composer -V

Nếu PowerShell báo không nhận ra lệnh, kiểm tra chương trình đã cài và thư mục chứa tệp thực thi đã được thêm vào PATH chưa; mở terminal mới sau khi thay đổi PATH. Nếu dùng XAMPP, PHP trong XAMPP có thể khác bản PHP được lệnh php tìm thấy. Dùng where.exe php để xem các đường dẫn trên Windows. Composer cần PHP CLI hoạt động.

Tải từ nguồn chính thức: PHP, Composer, XAMPP. Kiểm tra phiên bản và hướng dẫn tương thích trước khi cài; không cần cấu hình production cho bài này.

4. Chạy bằng CLI

Tạo thư mục thực hành của bạn rồi tạo tệp hello.php với nội dung:

<?php
$name = 'Nghia';
echo 'Xin chào ' . $name . PHP_EOL;

Mở terminal tại thư mục chứa tệp và chạy:

php hello.php

Kết quả mong đợi là Xin chào Nghia. Biến PHP bắt đầu bằng $; dấu . nối chuỗi; PHP_EOL là ký tự xuống dòng phù hợp môi trường.

Nếu báo không tìm thấy tệp, kiểm tra thư mục hiện tại bằng Get-Location và liệt kê tệp bằng Get-ChildItem. Nếu báo lỗi cú pháp, xem tên tệp và dòng lỗi; để kiểm tra cú pháp không chạy mã, dùng php -l hello.php.

5. Chạy qua trình duyệt

Trong terminal, tại thư mục chứa hello.php, chạy:

php -S localhost:8000

Mở http://localhost:8000/hello.php trong trình duyệt. Terminal cần tiếp tục chạy; nhấn Ctrl+C trong terminal để dừng server khi xong. Máy chủ tích hợp này dành cho phát triển, không dùng triển khai production.

Không mở tệp PHP bằng cách nhấp đúp hoặc qua server tĩnh rồi kỳ vọng PHP chạy: cần một server được cấu hình xử lý PHP. Nếu cổng 8000 đang bận, chọn một cổng cục bộ còn trống và thay cùng số cổng trong URL.

6. PHP bên trong HTML

Tạo info.php. Khi chèn dữ liệu vào HTML, escape để trình duyệt hiển thị văn bản thay vì diễn giải đầu vào thành thẻ.

<?php
$name = 'Nguyễn Văn An';
date_default_timezone_set('Asia/Ho_Chi_Minh');
?>
<!doctype html>
<html lang="vi">
<head><meta charset="utf-8"><title>Thông tin PHP</title></head>
<body>
  <h1>Xin chào <?= htmlspecialchars($name, ENT_QUOTES, 'UTF-8') ?></h1>
  <p>Giờ server: <?= date('d/m/Y H:i:s') ?></p>
  <p>Phiên bản PHP: <?= htmlspecialchars(PHP_VERSION, ENT_QUOTES, 'UTF-8') ?></p>
</body>
</html>

<?= ... ?> in biểu thức; date() sử dụng múi giờ cấu hình trong chương trình. Giờ hiển thị là giờ của môi trường thực thi. Không công khai trang chứa cấu hình nhạy cảm hoặc thông tin chẩn đoán server.

7. Tách cấu hình

Tạo hai tệp trong cùng thư mục. __DIR__ giúp PHP tìm cấu hình theo thư mục tệp hiện tại, không phụ thuộc thư mục đang đứng trong terminal.

config.php

<?php
$appName = 'Student Learning';
$author = 'An';

app.php

<?php
require __DIR__ . '/config.php';
echo htmlspecialchars($appName, ENT_QUOTES, 'UTF-8');
echo ' — ';
echo htmlspecialchars($author, ENT_QUOTES, 'UTF-8');

Mở http://localhost:8000/app.php khi server đang chạy: kết quả mong đợi là Student Learning — An. require dừng thực thi khi tệp bắt buộc không tìm thấy. Ví dụ này chỉ chứa dữ liệu công khai; bí mật cần được cấu hình và bảo vệ phù hợp.

8. Bài tập theo lộ trình

  1. Chạy php -v, composer -V; tạo và chạy hello.php bằng CLI và qua trình duyệt.
  2. Tạo info.php hiển thị họ tên, ngày giờ server và phiên bản PHP; thử đổi tên sang tiếng Việt.
  3. Đặt tên ứng dụng, tác giả trong config.php rồi dùng require từ trang PHP.

Tự thử thêm

Đổi tên tệp cấu hình để xem lỗi require trong môi trường học tập, sau đó trả lại tên cũ; kiểm tra lỗi sai đường dẫn và kiểm tra cú pháp. Không bật thông tin lỗi chi tiết cho người dùng trên production.

9. Checklist cuối ngày

  • Giải thích được request → PHP → response.
  • Phân biệt được PHP CLI, server phát triển và Composer.
  • Chạy thành công tệp bằng CLI và trình duyệt.
  • Giải thích echo, biến $, nối chuỗi và require.
  • Biết kiểm tra thư mục hiện tại, PATH và lỗi cú pháp.
