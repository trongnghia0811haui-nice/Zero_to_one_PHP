PHP OOP: Class, Object và Encapsulation

Mục tiêu và chuẩn bị

Hiểu class và object, constructor/destructor, thuộc tính và phương thức; thiết kế Employee và Student với trạng thái hợp lệ được bảo vệ.

Lưu mỗi ví dụ vào một tệp .php riêng. Chạy php ten-tep.php; kiểm tra cú pháp bằng php -l ten-tep.php. Tự dự đoán kết quả trước khi chạy.

Class và object

Class là bản thiết kế gồm thuộc tính và phương thức; object là một thể hiện được tạo từ class. Mỗi object có trạng thái riêng, còn phương thức mô tả hành vi.

<?php
class Student {
    public string $name;
}
$first = new Student();
$first->name = "An";
$second = new Student();
$second->name = "Bình";
echo $first->name; // An

Toán tử -> truy cập thuộc tính hoặc phương thức của object; new tạo đối tượng.

Constructor và $this

__construct được gọi khi dùng new. Bên trong phương thức, $this chỉ object hiện tại. Constructor có thể kiểm tra dữ liệu để ngăn object xuất hiện ở trạng thái không hợp lệ.

<?php
class Student {
    public function __construct(private string $name) {
        if (trim($name) === "") {
            throw new InvalidArgumentException("Tên không được rỗng");
        }
    }
    public function getName(): string { return $this->name; }
}
$student = new Student("An");
echo $student->getName(); // An

private string $name trong constructor là property promotion: vừa khai báo thuộc tính vừa gán giá trị. Ví dụ này dùng PHP 8 trở lên.

Public, private và đóng gói

public có thể được truy cập bên ngoài class; private chỉ truy cập trực tiếp trong chính class khai báo. Encapsulation bảo vệ bất biến bằng các phương thức có kiểm tra, thay vì chỉ đổi thuộc tính sang private một cách hình thức.

<?php
class Employee {
    private int $age;
    public function __construct(int $age) { $this->setAge($age); }
    public function setAge(int $age): void {
        if ($age < 18) throw new InvalidArgumentException("Tuổi phải từ 18");
        $this->age = $age;
    }
    public function getAge(): int { return $this->age; }
}
$employee = new Employee(20);
echo $employee->getAge(); // 20

Không thể truy cập trực tiếp $employee->age từ bên ngoài class. Dùng try/catch trong mã gọi để thông báo lỗi hợp lý thay vì che giấu exception.

Định nghĩa hợp lệ cho lương

Trong bài tập, lương cơ bản phải lớn hơn 0. Kiểu float cho phép minh họa phép tính, nhưng dữ liệu tiền trong ứng dụng thực tế cần quy ước biểu diễn chính xác và kiểm tra làm tròn.

<?php
class Salary {
    public function __construct(private float $amount) {
        if ($amount <= 0) throw new InvalidArgumentException("Lương phải lớn hơn 0");
    }
    public function amount(): float { return $this->amount; }
}
echo (new Salary(1000000))->amount(); // 1000000

Kiểm tra giá trị tại mọi điểm có thể thay đổi trạng thái, kể cả constructor và setter.

Phương thức tính điểm

Phương thức có thể tính kết quả từ trạng thái object. Trước khi lấy trung bình, quyết định cách xử lý danh sách rỗng; có thể trả null, miễn là hợp đồng được ghi rõ.

<?php
class Student {
    public function __construct(private array $scores) {}
    public function average(): ?float {
        if (count($this->scores) === 0) return null;
        return array_sum($this->scores) / count($this->scores);
    }
}
var_dump((new Student([8, 9, 7]))->average()); // float(8)
var_dump((new Student([]))->average()); // NULL

?float cho phép float hoặc null. Ví dụ học tập chưa kiểm tra mỗi điểm; bài tập cần kiểm tra điểm số trong khoảng cho phép.

Destructor và vòng đời

__destruct có thể được gọi khi object bị giải phóng hoặc kết thúc request. Thứ tự và thời điểm phụ thuộc vòng đời tham chiếu, nên không dựa vào destructor cho nghiệp vụ quan trọng cần bảo đảm hoàn tất.

<?php
class Demo {
    public function __destruct() { echo "Object được giải phóng"; }
}
$demo = new Demo();
unset($demo); // giải phóng tham chiếu
echo "\nKết thúc";

Với tài nguyên quan trọng, ưu tiên API đóng tường minh và try/finally. Đừng in hoặc đưa dữ liệu nhạy cảm vào destructor.

Kiểm thử các bất biến

Kiểm tra cả giá trị hợp lệ và không hợp lệ: ví dụ tuổi 18, tuổi 17, lương bằng 0 và lương dương. Kiểm thử phải xác nhận exception dự kiến thay vì nuốt mọi lỗi.

<?php
class Person {
    public function __construct(private int $age) {
        if ($age < 18) throw new InvalidArgumentException("Tuổi không hợp lệ");
    }
}
try {
    new Person(17);
    throw new RuntimeException("Lẽ ra phải từ chối tuổi 17");
} catch (InvalidArgumentException $e) {
    echo "Đã từ chối tuổi 17";
}

Không bắt Throwable rồi báo thành công: một lỗi không liên quan có thể bị che giấu.

Bài tập theo lộ trình

  1. Xây dựng Employee có id, name, age, baseSalary private; constructor và setter kiểm tra tuổi từ 18, lương lớn hơn 0, tên hợp lệ.
  2. Xây dựng Student với getAverageScore() và getRank(); tự ghi rõ thang xếp loại, quy tắc điểm rỗng và kiểm tra điểm từ 0 đến 10.
  3. Tạo 5 đối tượng, xuất thành bảng HTML có escape; thử truy cập thuộc tính private trong tệp thử riêng để quan sát lỗi và kiểm tra các giá trị biên.

Ghi đầu vào, kết quả mong đợi và thực tế; kiểm tra cả trường hợp rỗng và biên.
