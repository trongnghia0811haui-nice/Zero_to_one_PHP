1. Mục tiêu và cách học

Sau bài này bạn có thể viết hàm có tham số và giá trị trả về; thao tác với mảng; đọc, sửa thuộc tính object; lọc, tìm, tính toán và sắp xếp danh sách sinh viên. Ưu tiên hiểu dữ liệu đi qua từng bước hơn ghi nhớ toàn bộ phương thức.

Chuẩn bị: trình duyệt và DevTools → Console, hoặc Node.js. Mỗi ví dụ có thể chạy riêng trừ khi có ghi chú. Tự nhập code, dự đoán kết quả, sau đó mới chạy.

2. Function — hàm là gì?

Hàm là một khối lệnh có tên, thực hiện công việc cụ thể khi được gọi. Tham số là tên biến trong định nghĩa; đối số là giá trị thực tế truyền vào. return gửi kết quả về nơi gọi và kết thúc hàm.

function tinhTrungBinh(a, b) {
    return (a + b) / 2;
}
const ketQua = tinhTrungBinh(7, 9);
console.log(ketQua); // 8

Ở đây a, b là tham số; 7, 9 là đối số. console.log chỉ in kết quả, không thay thế return. Nếu không trả về rõ ràng, hàm trả undefined.

Ba cách khai báo

function gapDoi(n) { return n * 2; }          // declaration
const gapBa = function (n) { return n * 3; }; // expression
const gapBon = (n) => n * 4;                  // arrow function
console.log(gapDoi(2), gapBa(2), gapBon(2)); // 4 6 8

Với arrow function có ngoặc nhọn, phải viết return khi cần trả kết quả. Biến khai báo bằng let hoặc const trong hàm chỉ tồn tại trong phạm vi tương ứng. So với Python, JavaScript dùng ngoặc nhọn để xác định khối lệnh.

Lỗi thường gặp

const sai = (n) => { n * 2; };
console.log(sai(3)); // undefined
const dung = (n) => n * 2;
console.log(dung(3)); // 6

3. Array — mảng

Mảng lưu các giá trị theo thứ tự, chỉ số bắt đầu từ 0. length cho biết số phần tử; phần tử cuối có chỉ số length - 1. Truy cập chỉ số không tồn tại thường nhận undefined.

const diem = [7, 8, 9];
console.log(diem[0]);             // 7
console.log(diem[diem.length - 1]); // 9
for (const value of diem) {
    console.log(value);
}

push thêm vào cuối và làm thay đổi mảng gốc. Khai báo const không làm mảng bất biến: nó chỉ ngăn gán lại biến.

const ten = ["An", "Bình"];
ten.push("Chi");
console.log(ten); // ["An", "Bình", "Chi"]

filter, map và reduce

filter chọn phần tử thỏa điều kiện; map tạo mảng mới bằng cách biến đổi mỗi phần tử; reduce gom nhiều giá trị thành một kết quả. Giá trị khởi tạo 0 cho phép tính tổng cả khi mảng rỗng.

const scores = [6, 8, 9];
console.log(scores.filter(score => score >= 8)); // [8, 9]
console.log(scores.map(score => score * 2));     // [12, 16, 18]
console.log(scores.reduce((sum, score) => sum + score, 0)); // 23

Chú ý: mảng mới từ filter hoặc spread chỉ sao chép phần vỏ; nếu phần tử là object thì các object bên trong vẫn được tham chiếu chung.

4. Object — đối tượng

Object gom dữ liệu dưới dạng cặp thuộc tính và giá trị. Dùng dấu chấm khi biết tên thuộc tính; dùng ngoặc vuông khi tên thuộc tính nằm trong biến.

const student = { id: 1, name: "An", age: 20, score: 8.5 };
console.log(student.name); // An
const key = "score";
console.log(student[key]); // 8.5
student.score = 9;
console.log(student.score); // 9

Khác với Python dictionary, object JavaScript thường dùng dấu chấm cho tên thuộc tính hợp lệ. Truy cập thuộc tính không tồn tại trả undefined; đọc tiếp thuộc tính của undefined sẽ gây lỗi.

Mảng các object

const students = [
    { id: 1, name: "An", score: 7 },
    { id: 2, name: "Bình", score: 9 },
    { id: 3, name: "Chi", score: 8 }
];
console.log(students[1].name); // Bình

5. Tìm kiếm và sắp xếp

find trả phần tử đầu tiên thỏa điều kiện, hoặc undefined nếu không tìm thấy. some trả boolean, hữu ích để kiểm tra trùng ID.

const students = [{ id: 1, name: "An", score: 7 },
                  { id: 2, name: "Bình", score: 9 }];
const found = students.find(student => student.id === 2);
console.log(found?.name); // Bình
console.log(students.some(student => student.id === 3)); // false

sort thay đổi mảng gốc. Khi cần giữ thứ tự ban đầu, sao chép mảng trước. Comparator b.score - a.score đặt điểm lớn trước.

const scores = [7, 10, 8];
const sorted = [...scores].sort((a, b) => b - a);
console.log(sorted); // [10, 8, 7]
console.log(scores); // [7, 10, 8]

Nếu chỉ gọi sort(), các giá trị được so sánh theo biểu diễn chuỗi theo mặc định, nên sắp xếp số có thể cho kết quả không mong muốn.

6. Thực hành có hướng dẫn: tính điểm trung bình

Bài toán: nhận mảng điểm; trả về trung bình, hoặc null nếu mảng rỗng. Xử lý mảng rỗng trước để tránh chia cho 0.

function average(scores) {
    if (scores.length === 0) return null;
    const sum = scores.reduce((total, score) => total + score, 0);
    return sum / scores.length;
}
console.log(average([7, 8, 9])); // 8
console.log(average([]));        // null

7. Mini project: quản lý sinh viên

Tạo mảng 5 sinh viên có id, name, age, score. Mỗi chức năng nên nhận dữ liệu qua tham số và trả kết quả để dễ kiểm tra.

  1. Tính điểm cao nhất và trung bình; định nghĩa kết quả khi danh sách rỗng.
  2. Lọc sinh viên có điểm từ 8 trở lên.
  3. Thêm sinh viên: dùng some để chặn ID trùng; quyết định thông báo khi dữ liệu không hợp lệ.
  4. Xóa theo ID, tìm theo tên không phân biệt hoa/thường. Thử từ khóa rỗng và tên tiếng Việt; thống nhất quy tắc so sánh của bạn.
  5. Tạo danh sách sắp xếp giảm dần theo điểm, bảo đảm thứ tự mảng gốc không đổi.
Gợi ý cho chức năng thêm
function addStudent(students, student) {
    if (students.some(item => item.id === student.id)) {
        return false; // Trùng ID, không thay đổi mảng
    }
    students.push(student);
    return true;
}

Đây là ví dụ tập trung vào ID trùng. Bài hoàn chỉnh cần kiểm tra thêm tên, tuổi và điểm trước khi gọi hàm.

8. Bài tập tự luyện

  1. Viết hàm nhận hai số và trả số lớn hơn. Thử hai số bằng nhau.
  2. Viết hàm đếm số chẵn trong mảng; thử mảng rỗng.
  3. Tạo mảng tên viết hoa từ mảng ban đầu bằng map.
  4. Dùng filter lấy sinh viên đạt điểm từ 8; bảo đảm danh sách cũ không bị sắp xếp lại.
  5. Viết hàm tìm sinh viên theo ID; xử lý khi ID không tồn tại.
  6. So sánh tác động của students.sort(...) và [...students].sort(...) lên mảng gốc.
