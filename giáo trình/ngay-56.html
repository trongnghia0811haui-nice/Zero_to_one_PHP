Mục tiêu và chuẩn bị

Hệ thống hóa kiến thức nền, luyện giải thích bằng ví dụ, giải bài PHP/SQL có giới hạn thời gian và xác định phần còn yếu.

Cần PHP CLI hoạt động theo Ngày 11. Ví dụ độc lập chạy bằng PHP CLI; đoạn Laravel, Blade hoặc SQL phải đặt vào dự án và môi trường tương ứng theo chú thích.

Cách ôn có chủ đích

Với mỗi chủ đề, tự giải thích khái niệm bằng lời, nêu khi nào dùng, một ví dụ và một lỗi thường gặp. Viết ngắn gọn trước khi xem lại tài liệu, sau đó đối chiếu và sửa.

Khái niệm → Khi nào dùng → Ví dụ → Sai lầm → Tự kiểm tra

Không cần thuộc lòng mọi cú pháp; cần biết tư duy và cách kiểm tra tài liệu chính thức.

PHP và dữ liệu

Ôn kiểu, so sánh ===/==, mảng, hàm, scope, exception và xử lý request. Dữ liệu người dùng là không đáng tin; validation, escape HTML và prepared statement giải quyết các vấn đề khác nhau.

<?php
$values = [1, 2, 2];
$counts = [];
foreach ($values as $value) {
    $counts[$value] = ($counts[$value] ?? 0) + 1;
}
print_r($counts); // 1 => 1, 2 => 2

Ví dụ đếm tần suất số. Khi đếm ký tự tiếng Việt cần xác định cách tách ký tự Unicode và extension phù hợp.

OOP và hợp đồng

Class là bản thiết kế, object là thể hiện. Encapsulation bảo vệ trạng thái; interface định nghĩa hợp đồng; kế thừa và đa hình giải quyết các mối quan hệ khác nhau.

<?php
interface Payable { public function amount(): float; }
class FixedPay implements Payable {
    public function __construct(private float $value) {}
    public function amount(): float { return $this->value; }
}
echo (new FixedPay(100))->amount(); // 100

Ví dụ chỉ minh họa interface; hệ thống tiền thực tế cần quy tắc kiểu dữ liệu và validation.

JOIN và tổng hợp

LEFT JOIN giữ bảng bên trái; COUNT(column) bỏ qua NULL. WHERE lọc dòng trước nhóm, HAVING lọc nhóm sau khi tính tổng hợp.

SELECT c.id, c.class_name, COUNT(s.id) AS total
FROM classes c
LEFT JOIN students s ON s.class_id = c.id
GROUP BY c.id, c.class_name
HAVING COUNT(s.id) >= 3;

Ví dụ sử dụng schema sinh viên trong lộ trình. Thử lớp có 0, 2 và 3 sinh viên trong DB thử nghiệm.

MVC và luồng HTTP

Router chọn handler theo method/path; controller điều phối; model xử lý dữ liệu; view trình bày. Authentication, authorization, validation và escape cần đúng ranh giới.

HTTP request → router → middleware → controller → model
                                              ↓
                                      view / JSON response

Vẽ luồng thêm sinh viên và chỉ ra nơi từ chối user không có quyền, dữ liệu sai và thao tác SQL lỗi.

Bài live coding 45 phút

Chia thời gian: đọc đề và làm rõ giả định, viết giải pháp, thử dữ liệu biên, giải thích độ phức tạp và kiểm tra lại. Chấp nhận nói rõ điều chưa chắc chắn thay vì bịa kết quả.

1. Đếm tần suất ký tự bằng PHP.
2. LEFT JOIN + GROUP BY + HAVING.
3. Thiết kế interface và class triển khai.

Tự viết không nhìn lời giải trước; với Unicode, nêu đơn vị đếm ký tự/code point/grapheme và kiểm tra extension.

Theo dõi lỗ hổng

Ghi lại lỗi theo chủ đề, nguyên nhân, ví dụ sai và việc cần làm. Chọn vài bài trọng tâm để luyện lại thay vì chỉ đọc đáp án.

Ví dụ: JOIN lớp rỗng → nhầm COUNT(*) và COUNT(s.id)
Hành động: tạo fixture lớp không có sinh viên và chạy lại truy vấn

Chỉ đánh dấu hiểu khi tự giải thích và xử lý được một ví dụ mới.
