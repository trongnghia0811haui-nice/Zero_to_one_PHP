PHP: PDO, MySQL và Prepared Statement

Mục lục← Ngày 25Ngày 27 →

Mục tiêu và chuẩn bị

Kết nối PHP tới MySQL với PDO, truyền dữ liệu bằng tham số và xây dựng các thao tác CRUD; kiểm tra lỗi, cấu hình và ranh giới trách nhiệm.

Thực hành trên cơ sở dữ liệu MySQL thử nghiệm riêng, không dùng dữ liệu quan trọng. Chuẩn bị schema từ bài trước khi chạy các truy vấn liên quan.

PDO là gì?

PDO cung cấp API nhất quán cho truy cập database, nhưng cú pháp SQL và một số hành vi vẫn phụ thuộc hệ quản trị. Extension pdo_mysql là driver cần cho MySQL.

php -m
# Kiểm tra có PDO và pdo_mysql trong danh sách

Từ PowerShell chạy php -m. Nếu không nhận lệnh php sau khi cài, mở terminal mới. Ví dụ kết nối cần MySQL đang chạy và database thử nghiệm.

Tách cấu hình và thông tin nhạy cảm

Đọc host, database và thông tin truy cập từ biến môi trường hoặc cơ chế cấu hình an toàn. Không commit .env, không đưa mật khẩu thật vào ví dụ, log hoặc thông báo lỗi.

<?php
return [
    "host" => getenv("DB_HOST") ?: "127.0.0.1",
    "database" => getenv("DB_NAME") ?: "student_management",
    "username" => getenv("DB_USER") ?: "",
    "password" => getenv("DB_PASSWORD") ?: "",
];

Lưu thành config.php trong môi trường học. Bắt buộc thiết lập tài khoản MySQL riêng có quyền vừa đủ; không dùng tài khoản root cho ứng dụng thực tế.

Tạo kết nối PDO

DSN xác định driver, máy chủ, database và charset. ERRMODE_EXCEPTION giúp lỗi không bị bỏ qua; FETCH_ASSOC trả hàng dạng mảng kết hợp. Chỉ định utf8mb4 để hỗ trợ Unicode.

<?php
$config = require __DIR__ . "/config.php";
$dsn = "mysql:host=" . $config["host"] . ";dbname=" . $config["database"] . ";charset=utf8mb4";
$pdo = new PDO($dsn, $config["username"], $config["password"], [
    PDO::ATTR_ERRMODE => PDO::ERRMODE_EXCEPTION,
    PDO::ATTR_DEFAULT_FETCH_MODE => PDO::FETCH_ASSOC,
    PDO::ATTR_EMULATE_PREPARES => false,
]);

Đây là đoạn kết nối dành cho file cạnh config.php và yêu cầu MySQL đang chạy. Trên production, không hiển thị thông báo exception chi tiết chứa cấu hình cho người dùng.

Prepared statement

Prepared statement tách giá trị đầu vào khỏi cấu trúc SQL. prepare tạo statement, execute truyền tham số, fetch đọc một dòng; kiểm tra false nếu không có kết quả.

<?php
// Giả sử $pdo là kết nối PDO hợp lệ.
$stmt = $pdo->prepare("SELECT id, name, email FROM students WHERE id = :id");
$stmt->execute(["id" => 1]);
$student = $stmt->fetch();
if ($student === false) {
    echo "Không tìm thấy";
} else {
    echo htmlspecialchars($student["name"], ENT_QUOTES, "UTF-8");
}

Đoạn này phụ thuộc kết nối và dữ liệu mẫu. Placeholder dành cho giá trị, không thể thay trực tiếp tên bảng hoặc cột: tên cột động phải chọn từ whitelist.

INSERT và dữ liệu mới

Validate dữ liệu ở server trước khi lưu, sau đó dùng tham số cho từng giá trị. Khóa ngoại và UNIQUE vẫn cần trong database để bảo vệ tính toàn vẹn kể cả khi có request cạnh tranh.

<?php
// Giả sử $pdo và $name, $email, $classId đã được tạo và validate.
$stmt = $pdo->prepare("INSERT INTO students (name, email, class_id) VALUES (:name, :email, :class_id)");
$stmt->execute(["name" => $name, "email" => $email, "class_id" => $classId]);
$id = $pdo->lastInsertId();

lastInsertId trả chuỗi theo API PDO; không giả định thành công nếu lệnh đã ném exception. Tránh hiển thị SQL hoặc thông tin kết nối nhạy cảm.

UPDATE, DELETE và rowCount

Dùng WHERE theo ID để giới hạn tác động; kiểm tra quyền trước thao tác. rowCount cho UPDATE có thể bằng 0 khi không thay đổi dữ liệu, vì vậy không luôn chứng minh ID không tồn tại.

<?php
// Giả sử $pdo, $id, $name đã được validate và user được phân quyền.
$stmt = $pdo->prepare("UPDATE students SET name = :name WHERE id = :id");
$stmt->execute(["name" => $name, "id" => $id]);
echo "Số dòng bị ảnh hưởng: " . $stmt->rowCount();

Khi xóa, cân nhắc khóa ngoại và CASCADE; thao tác trên môi trường thử nghiệm. Dùng POST và CSRF protection trong giao diện dùng session.

Tổ chức StudentRepository

Một repository học tập có thể nhận PDO qua constructor và cung cấp all, findById, create, update, delete. Phân biệt dữ liệu thiếu với lỗi truy vấn; không lặng lẽ bắt mọi exception rồi trả thành công.

<?php
final class StudentRepository {
    public function __construct(private PDO $pdo) {}
    public function findById(int $id): array|false {
        $statement = $this->pdo->prepare("SELECT id, name, email FROM students WHERE id = :id");
        $statement->execute(["id" => $id]);
        return $statement->fetch(PDO::FETCH_ASSOC);
    }
}

Đây chỉ là một phương thức minh họa, không phải toàn bộ repository. Bài tập cần triển khai đầy đủ CRUD và kiểm tra lỗi, quyền và dữ liệu.

Bài tập theo lộ trình

  1. Viết Database tạo PDO MySQL từ config.php/biến môi trường; bật ERRMODE_EXCEPTION, FETCH_ASSOC và utf8mb4.
  2. Xây dựng StudentRepository có all, findById, create, update, delete với prepared statement; kiểm tra đầu vào và tránh SQL injection.
  3. Chạy test đủ CRUD trên database MySQL thử nghiệm; xác nhận dữ liệu, thử ID không tồn tại, email trùng, khóa ngoại sai và lỗi kết nối.

Ghi đầu vào, kết quả mong đợi và thực tế; kiểm tra cả trường hợp rỗng và biên.

Tự kiểm tra và tổng kết

  • Tự giải thích từng khái niệm và chạy lại các ví dụ.
  • Hoàn thành bài tập và xử lý dữ liệu biên, dữ liệu sai.
  • So sánh kết quả thực tế với kết quả dự đoán và ghi lại lỗi.

Tham khảo MySQL Manual và PHP Manual, chọn đúng phiên bản đang dùng.
