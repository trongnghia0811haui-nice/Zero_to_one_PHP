PHP: Điều kiện và vòng lặp

1. Mục tiêu và chuẩn bị

Học cách rẽ nhánh và lặp trong PHP, so sánh với kiến thức JavaScript đã học, sau đó giải các bài toán năm nhuận và xử lý dãy số.

Cần PHP CLI hoạt động theo Ngày 11. Lưu từng ví dụ vào một tệp .php riêng và chạy php ten-tep.php. Nếu có lỗi, kiểm tra dòng báo lỗi và thử php -l ten-tep.php.

2. Điều kiện if, elseif và else

Điều kiện được kiểm tra theo thứ tự; nhánh đúng đầu tiên chạy. Nếu cần kiểm tra nhiều khoảng, đặt các khoảng chặt hơn trước. Dùng === khi muốn so sánh cả kiểu và giá trị.

<?php
$score = 8;
if ($score >= 8) {
    echo "Giỏi";
} elseif ($score >= 5) {
    echo "Đạt";
} else {
    echo "Cần cố gắng";
}

Tự gõ ví dụ vào tệp PHP, chạy bằng CLI, dự đoán kết quả và thử một giá trị khác.

3. Năm nhuận

Một năm nhuận nếu chia hết cho 400, hoặc chia hết cho 4 nhưng không chia hết cho 100. Ví dụ 2000 là năm nhuận, 1900 không phải, 2024 là năm nhuận.

<?php
$year = 2024;
$isLeap = ($year % 400 === 0) || ($year % 4 === 0 && $year % 100 !== 0);
var_dump($isLeap); // bool(true)

Tự gõ ví dụ vào tệp PHP, chạy bằng CLI, dự đoán kết quả và thử một giá trị khác.

4. switch

switch thuận tiện khi so sánh một biểu thức với các giá trị cụ thể. break thoát switch; thiếu break có thể khiến các nhánh sau cũng chạy. Trong PHP, switch dùng so sánh lỏng nên cần chú ý kiểu dữ liệu.

<?php
$day = 2;
switch ($day) {
    case 2: echo "Thứ hai"; break;
    case 3: echo "Thứ ba"; break;
    default: echo "Ngày khác";
}

Tự gõ ví dụ vào tệp PHP, chạy bằng CLI, dự đoán kết quả và thử một giá trị khác.

5. for và while

for phù hợp khi biết cách khởi tạo, điều kiện và cập nhật biến đếm. while kiểm tra điều kiện trước mỗi lần lặp. Cần cập nhật biến để điều kiện dừng cuối cùng trở thành false.

<?php
for ($i = 1; $i <= 3; $i++) {
    echo $i . PHP_EOL;
}
// 1, 2, 3 trên các dòng riêng

Tự gõ ví dụ vào tệp PHP, chạy bằng CLI, dự đoán kết quả và thử một giá trị khác.

6. foreach và mảng rỗng

foreach duyệt từng giá trị trong mảng. Khi tìm giá trị lớn nhất, xử lý mảng rỗng trước khi lấy phần tử đầu tiên, sau đó cập nhật biến max trong vòng lặp.

<?php
$numbers = [4, 9, 2];
$max = $numbers[0];
foreach ($numbers as $number) {
    if ($number > $max) $max = $number;
}
echo $max; // 9

Tự gõ ví dụ vào tệp PHP, chạy bằng CLI, dự đoán kết quả và thử một giá trị khác.

7. Ví dụ Fibonacci

Hai giá trị đầu lần lượt là 0 và 1; giá trị tiếp theo bằng tổng hai số trước. Trước khi chạy, cần kiểm tra n là số nguyên không âm và giới hạn kích thước phù hợp để tránh số quá lớn.

<?php
$n = 6; $a = 0; $b = 1;
for ($i = 0; $i < $n; $i++) {
    echo $a . " ";
    $next = $a + $b; $a = $b; $b = $next;
}
// 0 1 1 2 3 5

Tự gõ ví dụ vào tệp PHP, chạy bằng CLI, dự đoán kết quả và thử một giá trị khác.

8. Bài tập theo lộ trình

  1. Kiểm tra năm nhuận và tính tiền điện theo ba bậc; tự ghi rõ đơn giá giả định và tính từng phần theo mức tiêu thụ.
  2. In N số Fibonacci đầu tiên và các số nguyên tố từ 1 đến 100; kiểm tra 0, 1, 2 và số âm.
  3. Duyệt mảng bằng foreach để tính max, min, tổng, đếm số chẵn/lẻ; không dùng max/min có sẵn và xử lý mảng rỗng.

Tự viết và chạy thử trước khi so sánh với ví dụ. Ghi lại dữ liệu đầu vào, kết quả mong đợi và kết quả thực tế.
