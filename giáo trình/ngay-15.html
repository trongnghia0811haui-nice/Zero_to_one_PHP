PHP: Mảng, mảng kết hợp và mảng đa chiều

Mục tiêu và chuẩn bị

Lưu dữ liệu sinh viên trong mảng đa chiều, duyệt và biến đổi danh sách, lọc học bổng, sắp xếp theo điểm mà không gây nhầm lẫn về khóa và dữ liệu gốc.

Lưu mỗi ví dụ vào một tệp .php riêng. Chạy php ten-tep.php; kiểm tra cú pháp bằng php -l ten-tep.php. Tự dự đoán kết quả trước khi chạy.

Mảng đánh số và mảng kết hợp

Mảng PHP là cấu trúc có thứ tự gồm các cặp khóa–giá trị. Mảng có thể dùng khóa số cho danh sách hoặc chuỗi cho dữ liệu có tên; đừng giả định mọi mảng đều có khóa liên tục.

<?php
$scores = [8, 7, 9];
$student = ["name" => "An", "age" => 20];
echo $scores[0] . PHP_EOL; // 8
echo $student["name"]; // An

Kiểm tra khóa tồn tại trước khi đọc dữ liệu đầu vào không chắc chắn. Toán tử ?? cung cấp giá trị mặc định nếu khóa thiếu hoặc có giá trị null.

Duyệt với foreach

foreach có dạng lấy giá trị hoặc cả khóa và giá trị. Tên khóa của mảng kết hợp giúp ta truy cập dữ liệu rõ ràng hơn thay vì dựa vào vị trí.

<?php
$student = ["name" => "An", "class" => "CNTT"];
foreach ($student as $key => $value) {
    echo "$key: $value" . PHP_EOL;
}
// name: An
// class: CNTT

Nếu dữ liệu đầu vào có thể chứa mảng lồng nhau, đừng giả định mọi giá trị đều là chuỗi in trực tiếp được.

Mảng đa chiều

Mỗi phần tử của danh sách sinh viên có thể là một mảng kết hợp, trong đó scores là một mảng con. Đọc theo từng cấp bằng khóa tương ứng.

<?php
$students = [
    ["id" => 1, "name" => "An", "scores" => ["math" => 8, "lit" => 7, "eng" => 9]],
    ["id" => 2, "name" => "Bình", "scores" => ["math" => 9, "lit" => 8, "eng" => 10]],
];
echo $students[0]["scores"]["math"]; // 8

Ví dụ truy cập điểm Toán của phần tử đầu. Trước khi xử lý file hoặc request, cần xác minh trường tồn tại và đúng kiểu.

Tính điểm bằng array_map

array_map tạo mảng kết quả bằng cách áp dụng callback lên từng phần tử. Ví dụ sau thêm avg vào bản sao của từng sinh viên, không ghi đè biến danh sách ban đầu.

<?php
$students = [["name" => "An", "scores" => [8, 7, 9]]];
$withAverage = array_map(function (array $student): array {
    $scores = $student["scores"];
    $student["avg"] = count($scores) ? array_sum($scores) / count($scores) : null;
    return $student;
}, $students);
var_dump($withAverage[0]["avg"]); // int(8) với PHP 8.4, vì phép chia số nguyên cho kết quả chính xác

Quy định rõ điểm rỗng trả null thay vì chia cho 0. Trong bài thực tế cũng cần xác thực điểm là số trong khoảng 0–10.

Lọc dữ liệu với array_filter

array_filter chọn những phần tử mà callback trả true. Theo mặc định, nó giữ nguyên khóa; array_values tạo lại chỉ số số liên tục khi cần xuất JSON thành danh sách.

<?php
$students = [["name" => "An", "avg" => 7], ["name" => "Bình", "avg" => 9]];
$eligible = array_values(array_filter($students, fn(array $s): bool => $s["avg"] >= 8));
echo $eligible[0]["name"]; // Bình

Không gọi array_values nếu khóa ban đầu có ý nghĩa nghiệp vụ cần giữ lại.

Sắp xếp với usort

usort sắp xếp mảng được truyền vào và đánh lại khóa số. Toán tử spaceship <=> trả số âm, không hoặc dương theo thứ tự so sánh; đổi chiều toán hạng để sắp xếp giảm dần.

<?php
$students = [["name" => "An", "avg" => 7], ["name" => "Bình", "avg" => 9]];
$sorted = $students;
usort($sorted, fn(array $a, array $b): int => $b["avg"] <=> $a["avg"]);
echo $sorted[0]["name"] . PHP_EOL; // Bình
echo $students[0]["name"]; // An

Xác định cách xử lý avg null trước khi sắp xếp danh sách thực tế; không chỉ dựa vào ép kiểu tự động.

Hiển thị dữ liệu trong HTML

Escape dữ liệu văn bản trước khi đưa vào HTML để các ký tự đặc biệt không trở thành markup. Bảng HTML dùng thead, tbody và th; dữ liệu số vẫn cần kiểm tra và định dạng phù hợp.

<?php
$student = ["name" => "An & Bình", "avg" => 8.5];
echo "<tr><td>" . htmlspecialchars($student["name"], ENT_QUOTES, "UTF-8") . "</td>";
echo "<td>" . number_format($student["avg"], 1) . "</td></tr>";

Đây chỉ là một hàng HTML; đặt kết quả trong table và tbody khi tạo trang hoàn chỉnh. number_format trả về chuỗi hiển thị.

Bài tập theo lộ trình

  1. Tạo mảng đa chiều gồm 6 sinh viên có id, name, class và scores gồm math, lit, eng.
  2. Dùng array_map tính điểm trung bình, array_filter lọc sinh viên đạt học bổng từ 8, usort sắp xếp điểm giảm dần.
  3. Hiển thị bảng danh sách, tổng số sinh viên và sinh viên có điểm cao nhất; xử lý dữ liệu rỗng, điểm không hợp lệ và trường hợp đồng điểm.

Ghi đầu vào, kết quả mong đợi và thực tế; kiểm tra cả trường hợp rỗng và biên.

Tự kiểm tra và tổng kết

  • Tự giải thích từng khái niệm và chạy lại các ví dụ.
  • Hoàn thành bài tập và xử lý dữ liệu biên, dữ liệu sai.
  • So sánh kết quả thực tế với kết quả dự đoán và ghi lại lỗi.
